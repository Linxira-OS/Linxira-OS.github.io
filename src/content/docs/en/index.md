<h1>Linxira OS Documentation</h1>
<p>Welcome to the official Linxira OS documentation. Linxira is a Direct Arch workstation: it uses <code>pacman</code> and the official Arch repositories, with Linxira-owned packages delivered through a separate signed repository. For general Arch Linux questions, refer to the <a href="https://wiki.archlinux.org/" target="_blank">Arch Wiki</a>.</p>
<p>On the Live desktop, Linxira Welcome opens automatically and provides the manual Calamares launch entry. Welcome, Calamares, Config Hub, and Shelly recommendation links read the same reviewed catalog v2. Shelly handles graphical software management after installation, not installer transactions.</p>
