<h1>Ecosystem</h1>
<p>The Linxira OS software ecosystem consists of <strong>107 curated applications</strong> across 14 categories, every one of them passing the <strong>catalog v3 review</strong> (license / source / availability). Available applications install with <code>pacman</code> from the official signed repository <a href="https://github.com/Linxira-OS/linxira-packages/tree/main/x86_64" target="_blank">[linxira]</a>. The <span class="tag rec">Recommended</span> tag marks everyday applications the maintainers recommend; <span class="tag prop">Proprietary</span> only means the <b>license is not open source</b> (per the catalog license classification, e.g. Steam or WPS Office) — it says nothing about who develops it. Those applications ask you to accept their license on install.</p>
<p style="color:var(--t-text-muted);font-size:0.9rem;">This list is generated by <code>scripts/gen-ecosystem-docs.mjs</code> from catalog v3; card counts and per-category totals come from that single dataset. Do not hand-edit the cards.</p>
