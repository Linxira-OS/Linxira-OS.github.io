<h1>Software Management</h1>
<p>Linxira is built directly on Arch Linux. Native packages use <code>pacman</code>, the official Arch repositories, and the separate signed Linxira repository.</p>
<h2>Shelly</h2>
<p>Shelly is the default graphical software manager after installation. It is optional post-install software, not an installer dependency; Calamares owns installation transactions.</p>
<h2>Optional Sources</h2>
<p>AUR, Flatpak, and AppImage support are disabled by default and require explicit user opt-in. Catalog v2 records reviewed recommendations and source boundaries, while Shelly performs the approved package operations.</p>
