01参考 · Linxira 设计语言

  • 直角方形几何，无圆角 —— "Scale L"（刻度尺 L）
  • 深墨轴线 + 浅色刻度：负空间"测量仪器"语言
  • 珊瑚色终点指针：全图唯一强调色落点
  • LZ 中的 L 直接沿用家族 L 标记，Z 用同语言补全

02为什么是 LZ

单字母 Z 与 GLM 桌面 CLI / Desktop 撞标；LZ 双字母 = Linxira + Zeta，家族前缀 + 产品字母，L 可直接复用主站 Scale L 的识别度，Z 按同一语言补全。

03候选版式

版式 1 · 横排同构
L | Z 并排 · Scale 对
家族同构 ★★★ · 小尺寸 ★★ · 独特性 ★★★

思路：L 用原版 Scale L，Z 用同语言补全：横杠 + 刻度梁 + 珊瑚落点。两个刻度尺并排，读作 "L Z"。适合导航栏 / 页面头部。
风险：横向长，favicon 尺寸需裁切或换竖排。

版式 3 · 共底合体
LZ Monogram 单形
家族同构 ★★★ · 小尺寸 ★★★ · 独特性 ★★★

思路：L 竖轴 + Z 顶杠与 45° 楔形 + 共用底杠，一个字读出 "LZ"；竖轴刻度延续 L 语言，珊瑚针落在楔形脚下（Z 的终点）。
